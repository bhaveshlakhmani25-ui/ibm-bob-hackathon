# Change Rehearsal - Integration

This folder contains the integration layer for Change Rehearsal.

## Purpose

Connect the core Change Rehearsal engine, AI analysis/backend, and the final developer-facing workflow.

## Integration Flow

Developer Change
→ Change Detection
→ Impact Analysis
→ AI Rehearsal
→ Risk & Affected Areas
→ Rehearsal Scenarios
→ Developer Report

## Current Status

Integration layer is being prepared while the core components are under development.
